DenPlus 独自機能・パラメーター使い方ガイド

本書は、DenPlus で追加・拡張された独自機能およびパラメーターの使い方ガイドです。
lilToon 本体の基本機能（メインカラー、基本的な影設定など）と同じ項目は割愛し、本シェーダーならではの追加機能・独自設定のみ を解説しています。

本書では技術的な詳細を省き、各パラメーターの調整目的と、値の変更による外観の変化について簡潔に説明します。

目次

  1. スペキュラー 2nd / 3rd（追加ハイライト）
  2. ワールド固定マットキャップ（環境反射）
  3. ノーマルマップ 3rd / 4th（追加凹凸・アニメーション）
  4. リムライト 2nd / 3rd（追加輪郭光・リムシャドウ）
  5. ノイズマスク（共通）（質感・ラメ表現）
  6. 補助機能（自動マスクパッキング・設定コピー）

1. スペキュラー 2nd / 3rd（追加ハイライト）

lilToon 本体の「反射」に加えて、独立したハイライトをさらに 2層（2nd / 3rd） 重ねて設定できます。

主な用途:

  • 広範囲の柔らかい光沢と、中心部の鋭いハイライトを多層化する
  • 自動車塗装やネイル、レジンのような透明コーティング層（クリアコート）を付与する
  • ワールド光源の向きに左右されず、髪や瞳に安定したハイライトを配置する

独自パラメーター

クリアコート (Clear Coat)

  • 目的: 塗料のクリア層、樹脂（レジン）、ネイル、光沢ニスのような透明コーティング層を表現します。
  • 効果:
    • 有効 (ON): 反射率がコーティング層に適した値（0.04）に固定され、斜めから見た際に下地の明るさが自然に減衰します。金属度および反射率のスライダーは非表示になります。
    • 無効 (OFF): 通常のスペキュラー層として機能し、金属度および反射率を個別に設定できます。

フレネル強度 / フレネルの鋭さ (Fresnel Strength / Fresnel Power)

  • 目的: 正面向きの面に対し、輪郭部（視線に対して斜めを向いた面）の反射強度を制御します。
  • 効果:
    • フレネル強度: 値を大きくするほど、斜め方向からの光沢が強くなります（0 の場合は視線角度による変化はありません）。
    • フレネルの鋭さ: 値を大きくするほど、反射の発生領域が外縁部のみに限定されます。値を小さくすると、より広い角度まで滑らかに広がります。

ライトの明るさを反映 (Enable Lighting)

  • 目的: ワールド光源の明るさおよび光色をハイライトに反映する度合いを設定します。
  • 効果:
    • 1.0 (初期値): 暗所ではハイライトが暗くなり、光源の色味に従います。
    • 0.0: 環境の明るさに関わらずハイライトが一定の明るさを維持します（イラスト調の表現や常時発光させたい場合に適します）。

光源方向の補正 / 補正方向 (Light Direction Override / Override Direction)

  • 目的: ワールド光源の向きに関わらず、指定した方向から光が当たっているかのようにハイライトを発生させます。
  • 効果:
    • 光源方向の補正 (0.0 〜 1.0): 値を大きくするほど、ワールドの主光源方向から「補正方向」で指定した方向へ光の向きがシフトします（明るさ自体は環境のライティングに従います）。
    • 補正方向 (カメラ基準: X=右, Y=上, Z=手前): 基準となる疑似光源の向きを指定します。例として (0, 0.5, 1) を指定すると、視点の斜め手前から光が当たっている状態となり、カメラアングルに連動した安定したハイライトを維持できます。

ノイズ強度 / タイリング / オフセット (Noise Strength / Tiling / Offset)

  • 目的: 均一なハイライトに対し、粗面やラメ粒子のような不均一な質感を付与します。
  • 効果: ノイズマスク（共通） のテクスチャを参照します。
    • ノイズ強度: 値を大きくするほど、ノイズパターンによる光沢の減衰・分離が強くなります。
    • タイリング / オフセット: ノイズパターンの密度（細かさ）および位置を調整します。

2. ワールド固定マットキャップ（環境反射）

一般的な MatCap はカメラ視点に追従するため、アバターの回転時にも反射像が画面に対して静止します。本機能では、ワールド空間に固定された疑似的な環境反射 を単一テクスチャで実現します。

主な用途:

  • 金属や装飾品に対し、空間に固定されたリアルな映り込みを付与する
  • アバターの動作やカメラ移動に合わせて反射像を自然に移動させる
  • テクスチャファイルを再編集することなく、Unity 上で色味やコントラストを調整する

独自パラメーター

ワールド固定 (World Fixing)

  • 目的: 反射像の追従基準を「カメラ視点」とするか「ワールド空間」とするかを切り替えます。
  • 効果:
    • 0.0 (視点追従): 従来の MatCap と同様にカメラ基準でサンプリングされます。
    • 1.0 (完全ワールド固定): 反射像がワールド座標に固定され、オブジェクトの回転に伴い反射が滑らかに遷移します。
    • 0.1 〜 0.9 (中間ブレンド): 視点追従とワールド固定の参照方向を補間し、視点移動に対して緩やかに追従する挙動になります。

ワールド回転 (Y軸) (World Rotation (Yaw))

  • 目的: ワールド固定が有効（> 0）の際、反射像の水平方向の向き（方位角）を調整します。
  • 効果: 反射像を Y 軸周りに回転させ、ハイライトや景色の映り込む位置を任意の方位に合わせます。

色相 / 彩度 / 明度 / ガンマ (Hue / Saturation / Value / Gamma)

  • 目的: マテリアルインスペクター上でテクスチャのトーン補正を行います。
  • 効果:
    • 色相: 全体の色合いをシフトします。
    • 彩度: 鮮やかさを増減します（0 でモノクロ化）。
    • 明度: 明るさを調整します。
    • ガンマ: コントラストカーブを調整します。

メインカラーの強度 (Main Color Power)

  • 目的: メインカラー（ベーステクスチャ色）を MatCap 反射に乗算する度合いを調整します。
  • 効果: 値を大きくするほど地肌や衣服の色調が強く反映され、下地との調和を高めます。

追加ライトについて

  • MatCap は環境反射として主光源の描画（ForwardBase）でのみ処理します。ポイントライトやスポットライトなどの追加光源（ForwardAdd パス）では描画されず、追加ライトごとに重ねて明るくなることはありません。

3. ノーマルマップ 3rd / 4th（追加凹凸・アニメーション）

lilToon の標準スロット（1st / 2nd）を保持したまま、その上にさらに 第3・第4の法線レイヤー（3rd / 4th） を重ねて合成できます。

主な用途:

  • 基本ディテールを維持したまま、水滴、刺繍、ダメージ表現などの追加テクスチャを重ねる
  • 法線パターンの UV スクロールや回転によるアニメーション効果を付与する
  • 微細な法線マップによる遠距離でのモアレ・エイリアシング（チラつき）を抑制する

独自パラメーター

UV 選択 (UV Mode: UV0 / UV1 / UV2 / UV3)

  • 目的: 適用する UV 座標チャンネルを選択します。

スクロール / 角度 / 回転速度 (UV Scroll / Angle / Rotation Speed)

  • 目的: 法線テクスチャの配置角度およびアニメーション動作を設定します。
  • 効果:
    • スクロール (X / Y): 表面に沿ってテクスチャを連続移動させます（流水、水滴、走査線など）。
    • 角度: テクスチャの静的回転角度を設定します。
    • 回転速度: テクスチャを継続的に旋回させます（渦巻きなど）。

距離フェード開始 / 終了 / 強度 (Distance Fade Start / End / Strength)

  • 目的: カメラからの距離に応じて法線強度を減衰させ、遠距離におけるピクセルのチラつき（エイリアシング・モアレ）を抑制します。
  • 効果:
    • 距離フェード開始 (m): 強度の減衰を開始するカメラ距離を指定します。
    • 距離フェード終了 (m): 法線強度が完全に設定値まで低下するカメラ距離を指定します。
    • 距離フェード強度: 終了距離において法線強度を減衰させる割合（1.0 で完全に平滑化）を指定します。

    設定例: 微細な布地パターン等の場合、開始 2.0m / 終了 6.0m / 強度 1.0 に設定することで、近接時のディテールを維持したまま遠景でのノイズを低減できます。

4. リムライト 2nd / 3rd（追加輪郭光・リムシャドウ）

キャラクターの輪郭部に光彩を付与するリムライトを、さらに 2層（2nd / 3rd） 独立して追加できます。

主な用途:

  • 天頂光と地表照り返しなど、上下で異なる光色のリムライトを多層化する
  • 加算発光だけでなく、輪郭部を暗く落とし込むシャドウ表現（リムシェード）を行う
  • 逆光時に自動で輪郭の輝度をブーストする

独自パラメーター

合成モード (Blend Mode)

  • 目的: リムライトの合成方式を切り替えます。
  • 効果:
    • 通常 (Normal): ベースカラーをリムカラーで置換補間します。
    • 加算 (Add): ベースカラーにリムカラーを加算します（強い光沢・発光）。
    • スクリーン (Screen): 白飛びを抑制しながら明るく合成します。
    • 乗算 (Multiply): 輪郭部を暗く落とし込みます。イラスト調の輪郭影表現や、ベルベット等の起毛素材のエッジ減衰表現に適しています。

リムライトの方向 (+上 / -下) (Rim Light Direction / Vertical Bias)

  • 目的: リムライトの発生領域をワールド空間の垂直軸（上下）に基づいて限定します。
  • 効果:
    • 正の値 (+): 上向きの面に限定されます（天頂光・太陽光の表現）。
    • 負の値 (-): 下向きの面に限定されます（地表や水面からの照り返しの表現）。
    • 0.0: 輪郭全体に均等に適用されます。

逆光ブースト (Backlight Boost)

  • 目的: 視線と主光源が対向する（逆光）状態において、リムライトの強度を自動的に増幅します。
  • 効果: 逆光アングルにおいて輪郭光が強調され、順光アングルでは標準の強度に戻ります。

境界 (Border) / ぼかし (Blur)

  • 目的: リムライトの範囲および輪郭の境界硬度を調整します。
  • 効果:
    • 境界: リムライトが発生する領域の幅（しきい値）を設定します。
    • ぼかし: 階調の滑らかさを調整します。値を大きくするとグラデーション状になり、小さくするとセル画調のシャープな境界になります。

ライトの明るさを反映 (Enable Lighting)

  • 目的: 環境光源の明るさをリムライト色に乗算するかを設定します。
  • 効果:
    • 1.0 (初期値): 暗所においてリムライトが自然に減衰します。
    • 0.0: 暗所でも設定した輝度を維持します（乗算モード時は無効）。

5. ノイズマスク（共通）（質感・ラメ表現）

インスペクター下部の 「ノイズマスク（共通）」 スロットにグレースケールテクスチャを1枚指定することで、各追加レイヤーから参照可能になります。

  • スペキュラー 2nd / 3rd: ハイライトを粒状に分散させ、ラメや粗面の質感を付与
  • マットキャップ: 金属表面にヘアライン加工や微細な粗さを付与
  • リムライト 2nd / 3rd: 輪郭光の境界を粒子状に減衰

仕様:
テクスチャスロット自体は共有ですが、タイリングおよびオフセットは各機能側で個別に設定可能です。機能ごとに異なる密度で同一ノイズを利用できます。

6. 補助機能

自動マスクパッキング

  • 概要: シェーダーが宣言するテクスチャ数が GPU / API 上限（64枚）を超過するのを回避するため、各機能に割り当てられた単一チャンネルマスクをバックグラウンドで自動的に RGBA テクスチャへ統合（パッキング）して適用します。
  • 操作: ユーザーが特別な操作を行う必要はありません。各マスクスロットにテクスチャを割り当てることで自動的にパッキングされます。
    外部での画像編集などが即座に反映されない場合は、「マスクパッキング状態」セクション内の 「パック済みマスクを再ベイク」 ボタンを実行してください。

設定のコピー＆ペースト

各機能セクションヘッダー右端の 「…（メニューアイコン）」 から、パラメーターの複製が行えます。

  • コピー (Copy): 数値およびカラー設定をクリップボードに保持します（テクスチャ参照は含みません）。
  • コピー (テクスチャを含む) (Copy (with textures)): テクスチャ参照を含めて全設定をコピーします。
  • 貼り付け (Paste): コピーした設定を同一または別のセクションへ適用します。
