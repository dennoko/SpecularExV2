# SpecularExV2 リリースノート（文案）

[feature_expansion_plan.md](feature_expansion_plan.md) の実装分に対するリリースノートの下書きです。

## 追加

### スペキュラー 2nd / 3rd
- **光源方向の補正**：ハイライトの光源方向をカメラ基準の方向へ寄せられます。ディレクショナルライトのないワールドでもハイライトが見える位置に出ます。明るさはワールドのライティングに従うので、暗い場所で光ることはありません。
- **ライトの明るさを反映**：ハイライトにライトの色・明るさを掛ける度合いを調整できます（既定値 1 で従来どおり）。
- **クリアコート**：塗装・ネイル・レジンのようなコート層を表現します。反射率を 0.04 に固定し、斜めから見たときに下地を暗くします。
- **フレネル強度 / 鋭さ**：斜めから見たときほどハイライトを強くします。

### マットキャップ
- **ワールド固定をスライダーに変更**：0 で通常のビュー、1 で完全にワールド固定です。中間の値では、ハイライトがカメラに少し遅れて付いてくる自然な映り込みになります。
- **テクスチャは1枚に**：後半球用のテクスチャスロットを廃止し、後半球は前半球の鏡像を使います（下記「移行」を参照）。
- **色相・彩度・明度・ガンマ**、**メインカラーの強度** を追加しました。

### ノーマルマップ 3rd
- **UV スクロール / 角度 / 回転速度**
- **距離フェード**：遠くで法線を弱め、VR でのちらつきやモアレを抑えます。

### ノーマルマップ 4th（新規）
- 3rd と同じ設定項目を持つ4枚目の法線マップです。3rd の上に重ねて合成します。
- マスクは既存のパックマスクにまとめられるため、マスク用のテクスチャは増えません。

### リムライト 2nd
- **境界**：リムの境目の位置を調整できます（既定値 0.5 で従来と同じ見た目）。
- **上下方向の制限**：上向き（+）または下向き（−）の面だけにリムを出します。
- **逆光ブースト**：逆光のときにリムを強くします。
- **ライトの明るさを反映**：リムの色にライトの色を掛けます。

### 共通ノイズマスク（新規）
- 1枚のノイズテクスチャを、スペキュラー・マットキャップ・リムライトから共通で参照できます。粗い表面のハイライトなどに使えます。
- 各機能で **ノイズ強度** と **タイリング / オフセット** を個別に設定できるので、同じテクスチャでも機能ごとに違う細かさで使えます。
- ノイズはマスクのパックテクスチャにまとめられるため、テクスチャ数は増えません。

## ⚠ 見た目が変わる変更

- **リムライト 2nd の「ライトの明るさを反映」の既定値は 1 です**（lilToon 本体のリムライトと同じ）。
  更新前のマテリアルでは、リムが暗い場所でも発光しているように見えていました。更新後は、ワールドの明るさに合わせて暗くなります。
  **従来の見た目を維持したい場合は、この値を 0 にしてください。**（合成モードが「乗算」のリムシェードは影響を受けません）

## 移行

- **マットキャップの後半球テクスチャ**を使っていたマテリアルでは、後半球にも前半球の鏡像が表示されるようになります。
- ワールド固定の設定はそのまま引き継がれます（ワールド固定 = 1）。

## 最適化

- **NDMF 導入時、アップロードに不要なテクスチャを含めないようにしました。** 個別マスク（パック前の元画像）は、パックマスクと二重にアップロードされていました。NDMF が導入されている場合、ビルド時の複製マテリアルから元マスクの参照を外します。無効な機能のテクスチャや、どの機能も使わないパックマスクも外します。プロジェクト内のマテリアルは変更されません。NDMF が導入されていない場合の動作は従来どおりです。
- **強度 0 の機能の処理を省略します。** 有効のまま強度（マットキャップ・リムは色のアルファも）を 0 にした機能は、テクスチャの読み取りと計算を行いません。アニメーションで強度を戻せば従来どおり表示されます。ノーマルマップ 3rd / 4th も強度 0 の層は合成を省略します。

## その他

- lilToonMulti でノーマルマップ系のキーワードが無いバリアントがコンパイルエラーになる問題を修正しました。
- マットキャップの後半球テクスチャを廃止し、マットキャップのサンプリングを2回から1回に減らしました。ノーマルマップ 4th の追加により、シェーダーが宣言するテクスチャ数は 5 のままです（テクスチャ数の上限 64 に対して十分な余裕があります）。
