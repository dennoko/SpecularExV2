# SpecularExV2 リリースノート（文案）

[feature_expansion_plan.md](feature_expansion_plan.md) の実装分に対するリリースノートの下書きです。

## 追加

### スペキュラー 2nd / 3rd
- **光源方向の補正**：ハイライトの光源方向をカメラ基準の方向へ寄せられます。ディレクショナルライトのないワールドでもハイライトが見える位置に出ます。明るさはワールドのライティングに従うので、暗い場所で光ることはありません。
- **ライトの明るさを反映 / 明るさ上限**：ハイライトの明るさをライトの明るさで制限できます。強度や HDR カラーを上げていても、暗いワールドでハイライトが浮かなくなります（上限は最大値で無制限）。
- **クリアコート**：塗装・ネイル・レジンのようなコート層を表現します。反射率を 0.04 に固定し、斜めから見たときに下地を暗くします。
- **フレネル強度 / 鋭さ**：斜めから見たときほどハイライトを強くします。

### マットキャップ
- **空間モード**：ビュー（通常）／ワールド固定／**オブジェクト固定（新規）**。オブジェクト固定では、反射がアバターの回転には追従し、カメラの動きには追従しません。
- **1枚のテクスチャで前後の半球を指定**：左右分割レイアウト（左半分 = 前半球、右半分 = 後半球）に対応しました。後半球用のテクスチャスロットは廃止しています（下記「移行」を参照）。
- **フレネル強度 / 鋭さ**、**色相・彩度・明度・ガンマ**、**メインカラーの強度** を追加しました。

### ノーマルマップ 3rd
- **UV スクロール / 角度 / 回転速度**
- **距離フェード**：遠くで法線を弱め、VR でのちらつきやモアレを抑えます。

### リムライト 2nd
- **境界**：リムの境目の位置を調整できます（既定値 0.5 で従来と同じ見た目）。
- **上下方向の制限**：上向き（+）または下向き（−）の面だけにリムを出します。
- **逆光ブースト**：逆光のときにリムを強くします。
- **ライトの明るさを反映**：リムの色にライトの色を掛けます。

## ⚠ 見た目が変わる変更

- **リムライト 2nd の「ライトの明るさを反映」の既定値は 1 です**（lilToon 本体のリムライトと同じ）。
  更新前のマテリアルでは、リムが暗い場所でも発光しているように見えていました。更新後は、ワールドの明るさに合わせて暗くなります。
  **従来の見た目を維持したい場合は、この値を 0 にしてください。**（合成モードが「乗算」のリムシェードは影響を受けません）

## 移行

- **マットキャップの後半球テクスチャ**を使っていたマテリアルでは、インスペクターに「前後を1枚に結合」ボタンが表示されます。押すと、前半球と後半球を左右に並べたテクスチャが生成され、自動で設定されます。
  - 生成先：`Assets/dennokoworks/SpecularExV2_Generated/MatcapAtlas/`
  - 未移行のままアップロードすると、ビルド時に警告が出ます（前半球の鏡像で描画されます）。
