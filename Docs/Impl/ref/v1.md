# v1 仕様・リファレンス (拡張スペキュラー / dennoko_specularex)

> **Note**  
> 本ドキュメントは v1 (`Assets/dennokoworks/Specular`) の仕様・マニュアルを整理したリファレンス資料です。  
> v2 の設計・機能拡張のベース資料として参照します。

---

## 1. 概要

`dennoko_specularex/lilToon` は、lilToon に **「2層のスペキュラー（Specular 1st / 2nd）」** および独立した **「拡張 MatCap（Extended MatCap）」** を追加した拡張シェーダーです。

- **2層スペキュラー**: 各層が独立してマスク、ノイズ、カラー、強度、スムースネス、ノーマル強度を設定可能。
- **チャンネル選択 (Channel Packing)**: マスク / ノイズ / 強度 / スムースネスの各テクスチャについて、参照するチャンネル（R / G / B / A）を個別に指定可能。
- **拡張 MatCap**: 標準 MatCap とは別に動作し、反射ベクトルサンプリング（疑似 Cubemap）や裏面無効化、ライティング・影追従を備える。

---

## 2. 動作環境・制約事項

- **Unity バージョン**: Unity 2022.3.22f1 確認済み
- **lilToon バージョン**: lilToon v2.3.1 確認済み
- **対応描画モード**:
  - 不透明 (Opaque)
  - カットアウト (Cutout)
  - 半透明 (Transparent)
  - ※ Lite などのバリアントも利用可能
- **注意事項**:
  - lilToon のカスタムシェーダー機能を利用しているため、lilToon が導入されたプロジェクトで動作します。
  - v1 時点ではリアルタイム影（リアル影）との併用は非サポート（併用時は通常の lilToon を使用）。

---

## 3. セットアップ手順

1. **シェーダーの割り当て**:
   - 対象マテリアルの Shader を `dennoko_specularex/lilToon`（またはバリアント）に変更します。
2. **インスペクターの確認**:
   - Material Inspector の `Custom Properties` 内に `Specular 1st`、`Specular 2nd`、`Extended MatCap` の各項目が表示されます。
3. **有効化とパラメーター調整**:
   - 使用したいレイヤーの「有効化」を ON にし、各パラメーターを設定します。

---

## 4. パラメーター仕様

### 4.1 スペキュラー機能（Specular 1st / Specular 2nd 共通）

1st と 2nd は同一のパラメーター構成を持ち、完全に独立して機能します。

| パラメーター名 | 設定値・範囲 | 説明 |
| :--- | :--- | :--- |
| **有効化** | Toggle (ON / OFF) | そのレイヤーのスペキュラーを有効化します（デフォルト: 1st のみ ON）。 |
| **Mask (R) + Channel** | Texture + Channel (R/G/B/A) | スペキュラーの適用範囲マスク（白＝適用、黒＝無効）。Tiling/Offset 設定可能。 |
| **Noise (R) + Channel** | Texture + Channel (R/G/B/A) | スペキュラー強度に乗算するノイズテクスチャ。反射のムラを作成可能。Tiling/Offset 設定可能。 |
| **カラーマップ使用** | Toggle (ON / OFF) | スペキュラーカラーの決定方法を切り替えます。 |
| └ **Color Map (RGB)** | Texture (RGB) | カラーマップ使用 ON 時に使用されるスペキュラーカラーテクスチャ。 |
| └ **色** | Color (RGB) | カラーマップ使用 OFF 時に使用される固定カラー。 |
| **強度マップ使用** | Toggle (ON / OFF) | スペキュラー強度の入力ソースを切り替えます。 |
| └ **Intensity Map + Channel** | Texture + Channel (R/G/B/A) | 強度マップ使用 ON 時に使用される強度マップ。 |
| └ **強度** | Float (0.0 〜 5.0) | 強度マップ使用 OFF 時に使用される固定強度スライダー。 |
| **スムースネスマップ使用** | Toggle (ON / OFF) | スムースネスの入力ソースを切り替えます。 |
| └ **Smoothness Map + Channel** | Texture + Channel (R/G/B/A) | スムースネスマップ使用 ON 時に使用されるマップ。 |
| └ **スムースネス** | Float (0.0 〜 1.0) | スムースネスマップ使用 OFF 時に使用される固定値。高いほどハイライトが鋭くなり、低いほど広がります。 |
| **ノーマル強度** | Float (0.0 〜 3.0) | レイヤーごとの法線の影響度。<br>・`0`: ベース法線（ノーマルマップ無効）<br>・`1`: メインノーマルマップのまま<br>・`1〜3`: 法線の傾きを強調 |

---

### 4.2 拡張 MatCap 機能（Extended MatCap）

金属的な質感や特定の環境光表現を追加するための独立 MatCap です。

| パラメーター名 | 設定値・範囲 | 説明 |
| :--- | :--- | :--- |
| **Enable** | Toggle (ON / OFF) | 拡張 MatCap 機能を有効化します。 |
| **Texture / Color** | Texture + Color | 使用する MatCap テクスチャおよび全体への乗算カラー。 |
| **Strength (Opacity)** | Float (0.0 〜 1.0) | MatCap の適用強度（不透明度）。 |
| **Blend Mode** | Enum (Add / Screen / Multiply) | 合成モードを選択します。<br>・`Add`: 加算合成（ハイライト・発光表現向け）<br>・`Screen`: スクリーン合成（明るく自然に馴染ませる）<br>・`Multiply`: 乗算合成（影や焼き込み表現向け） |
| **Blur** | Float / Texture LOD | MatCap テクスチャのぼかし具合。ラフな反射表現を作成する際に有効。 |
| **Mask** | Texture | 適用範囲マスク（白＝適用、黒＝無効）。Tiling/Offset 設定可能。 |
| **Normal Strength** | Float (0.0 〜 3.0) | MatCap 計算に使用する法線の詳細度（凹凸具合）。<br>・`0`: メッシュ本来の法線（マットな仕上がり）<br>・`1`: メインノーマルマップをそのまま使用<br>・`1以上`: ノーマルマップの凹凸を強調 |
| **Use Reflection** | Toggle (ON / OFF) | サンプリング方法の切り替え。<br>・`OFF` (Default): 通常の MatCap。カメラに対する法線の向きで決定（拡散光寄り）。<br>・`ON` (Reflection Mode): 反射ベクトルでサンプリング。視点移動に伴って映り込みが滑る鏡面的表現（疑似 Cubemap）。 |
| **Disable on Backface** | Toggle (ON / OFF) | ポリゴン裏面が描画される際に MatCap を無効化（黒マスク）。マントの裏地や髪の裏への不要な回り込みを防止。 |
| **Enable Lighting** | Float (0.0 〜 1.0) | 環境光やライトの明るさを MatCap に反映させる度合い。 |
| **Shadow Strength** | Float (0.0 〜 1.0) | 影の領域で MatCap を暗くする度合い。 |

## 5. 基本的な活用の例

1. **ベースの広いハイライト + 鋭いピンポイントハイライト**:
   - `Specular 1st`: スムースネス低め・強度広めで全体のベース反射を作成。
   - `Specular 2nd`: スムースネス高め・ノーマル強度強めでシャープなハイライトを追加。マスクやノイズで金属パーツや特定部位のみに限定。
2. **テクスチャのチャンネルパッキングによる最適化**:
   - 1枚のテクスチャに各マップをパック（例: R=Mask, G=Noise, B=Intensity, A=Smoothness）。
   - 各パラメーターの Channel 選択で対応するチャンネルを指定することで、テクスチャサンプリング数・VRAM を大幅に節約可能。

---

## 6. 設計・実装上の留意点

- **マスクとノイズの乗算**:
  - スペキュラー計算時、Mask 値と Noise 値は乗算されて最終的な寄与度が決まります。片方が 0 (黒) であればスペキュラーは無効化されます。
- **独立 UV 調整**:
  - Mask / Noise / 各種マップは個別に Tiling / Offset を調整できます。
- **ライト・影との相互作用**:
  - 影エリアではライトの影響度によりスペキュラーが自動的に減衰します。テクスチャの挙動を確認する際は明るい環境でのテストを推奨します。

## 7. トラブルシューティング

| 現象 | 主な原因と対処法 |
| :--- | :--- |
| **アバターアップロード後にマテリアルが透明になる** | 透明になったメッシュを選択し、Inspector に表示した状態で Unity 上部メニューの `Assets -> lilToon -> [Shaders] Refresh shaders` を実行してください。 |
| **パラメーターを動かしても変化が出ない** | ① 対象レイヤーの「有効化」が ON になっているか確認してください。<br>② Mask や Noise の乗算結果が黒 (0) になっていないか確認してください。 |
| **意図したチャンネルの値が反映されない** | プロパティ横のチャンネル選択ドロップダウン（R/G/B/A）が正しく選択されているか確認してください。 |
| **ハイライトが広がりすぎる / 鋭すぎる** | 「スムースネス」スライダーで調整してください（値を上げると鋭く小さくなり、下げると広がります）。ノーマル強度も併せて微調整すると効果的です。 |
